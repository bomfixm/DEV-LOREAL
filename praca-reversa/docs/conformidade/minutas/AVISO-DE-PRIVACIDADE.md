# 2. Dados de quem usa o sistema

- **Conta:** login, nome, perfil, unidades/clientes a que tem acesso e senha guardada apenas em formato protegido (hash), nunca em texto.
- **Uso:** registros do que cada pessoa fez no sistema (por exemplo: cadastro, movimentação, conferência, correção), com data e hora. Eles servem para rastrear o estoque e esclarecer divergências.
- **Segurança:** entradas, falhas de entrada, acessos negados e mudanças de conta. O endereço IP é usado no momento do login para limitar tentativas e aparece no registro técnico do servidor, que é substituído por tamanho. Ele não é gravado no banco de dados.
- **Sessão:** um cookie técnico de sessão, necessário para o sistema funcionar. Não há cookies de publicidade, de análise ou de terceiros.
- **Preferências no aparelho:** tema claro/escuro e forma do menu, guardados no próprio navegador.
- **Aceite dos termos (quando exigido):** versão aceita e data/hora, sem dados do aparelho.

# 3. Dados de terceiros nos registros da operação

Os registros de devolução trazem principalmente dados de empresas: número da nota, Delivery, remetente e CNPJ. Em alguns casos o remetente pode ser pessoa física, ou o nome empresarial pode conter o nome de uma pessoa. Esses dados são usados somente para localizar e devolver mercadorias.
